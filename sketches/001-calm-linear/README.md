## Variant: Calm Linear

### Design stance
Linear / Notion 风格的排版优先设计。白底、宽松间距、内容自上而下流动。

### Key choices
- **Layout**: 垂直单列，宽度受限（max-w-3xl），内容按自然阅读顺序流动
- **Typography**: Inter 字体，清晰的层次结构（h1 → 标签 → 说明文字）
- **Color**: 白底 + 灰色/indigo 点缀，干净、可信赖
- **Interaction**: 点击 Generate 和示例按钮有平滑动画过渡

### Trade-offs
- **Strong at**: 新用户易上手，SEO 友好（内容突出），转化率优先
- **Weak at**: 高级用户需要在结果和测试区之间反复切换时不够高效

### Best for
- Landing page 和免费用户的首次体验
- 内容型 SEO 引流（页面结构有利于 Google 阅读）
- 作为默认视图，给用户"这个工具很专业"的第一印象
