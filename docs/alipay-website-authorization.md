# 网站收款授权书（支付宝解限用）

> 用法：把下方「【】」改成真实信息 → 复制到 Word / 备忘录 → 打印（或导出 PDF）→ 甲乙双方签字/盖章 → 拍照上传到支付宝「网站补充信息」。
>
> 若网站备案主体与支付宝账号主体是同一人/同一公司，一般不必用本授权书，改传 ICP 备案截图即可。

---

鉴于乙方需在甲方网站上使用支付宝收款能力（含当面付 / 订单码支付等），双方达成如下约定：

### 一、授权网站

甲方确认并授权乙方在以下网站开展合法经营并收款：

- 主域名：【ststudio.top】  
- 业务站点：【https://regex.ststudio.top】  
- 其他页面（如有）：【https://regex.ststudio.top/cn/pricing】  

### 二、授权内容

1. 甲方同意乙方在上述网站接入支付宝支付产品，向用户展示支付入口、二维码并收取服务费用。  
2. 本授权仅限上述网站及与 Forge Regex / 正则相关的合法业务，不得用于违法违规用途。  
3. 收款资金进入乙方支付宝账户，由乙方自行承担税务、退款、售后等责任；与甲方无涉（双方另有约定除外）。  

### 三、声明与保证

1. 甲方声明对上述网站享有合法使用权（域名持有 / 备案主体 / 实际运营权），有权作出本授权。  
2. 乙方声明提交给支付宝的资料真实、准确，并遵守支付宝开放平台及监管要求。  
3. 若因授权不实、网站违规等导致支付宝限权、处罚或损失，由过错方承担责任。  

### 四、授权期限

自本授权书签署之日起至【2027年12月31日】止；期满双方无异议可自动顺延一年。  
甲方可书面通知提前终止授权；终止后乙方应停止在该网站使用甲方名义相关展示（不影响已完成的交易结算）。  

### 五、其他

1. 本授权书一式两份，甲乙双方各执一份，具有同等效力；电子扫描件/照片与原件具有同等效力（供支付宝审核）。  
2. 未尽事宜，双方可另行补充书面协议。

## 填写示例（个人自有站、主体其实是同一个人时）

若其实是「自己授权自己」，建议优先交备案截图。若审核仍要求授权书，可写成：

- 甲方、乙方填**同一姓名**  
- 证件号填同一身份证号  
- 在文首加一句：「甲方与乙方为同一主体，本授权书用于向支付宝说明网站与收款账号归属关系。」

## 上传小贴士

1. 手写签名清晰，尽量白纸黑字、光线均匀。  
2. 可把授权书首页 + 签字页各拍一张，或合成一页长图。  
3. 同页还需准备：网站/定价页截图、经营人入镜实景照。
