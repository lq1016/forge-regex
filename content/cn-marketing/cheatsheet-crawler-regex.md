# 爬虫 / HTML 正文 · 常用正则速查（JS / Python 友好）

> 提醒：复杂嵌套 HTML 优先用解析器（cheerio / lxml / BeautifulSoup）。正则适合「列表页抽链接、粗清洗、属性抽取」这类结构化较弱的场景。  
> 下列可在 https://www.ststudio.top/works/forge-regex 用中文描述生成，并立刻用样例测。

## 1. 抽 `<a href>`（单双引号）

```regex
<a\s+[^>]*?href\s*=\s*['"]([^'"]+)['"]
```

标志：`gi`  
捕获组 `$1` = URL。

## 2. 抽 `<title>` 标题

```regex
<title[^>]*>([\s\S]*?)<\/title>
```

标志：`i`  
`$1` = 标题文本。

## 3. 粗暴去标签（清洗正文）

```regex
<[^>]+>
```

标志：`g`  
**替换为空字符串**，再对 `&nbsp;` 等做二次替换。

## 4. 抽 `img` 的 `src` / `data-src`（懒加载）

```regex
<img[^>]+(?:data-src|src)\s*=\s*['"]([^'"]+)['"][^>]*>
```

标志：`gi`  
`$1` = 图片地址。优先匹配到的属性顺序取决于写法；需要「只要 data-src」时可改提示词再生成。

## 5. 抽 `meta description`

```regex
<meta\s+[^>]*name\s*=\s*['"]description['"][^>]*content\s*=\s*['"]([^'"]+)['"][^>]*>
```

也可兼容 content 在前的变体（再生成一条或写两条分别跑）。

## 6. 抽正文里的绝对 URL

```regex
https?:\/\/[^\s"'<>]+
```

标志：`gi`

## 7. 抽 HTML 注释（有时藏分页/接口）

```regex
<!--([\s\S]*?)-->
```

标志：`g`

## 8. 中文正文段落（粗筛）

```regex
[\u4e00-\u9fa5]{20,}
```

标志：`g`  
适合从杂乱文本里捞「像一段话」的中文；不是完美正文抽取。

## 9. 列表页「下一页」链接

提示词：

> 匹配包含「下一页」或「下页」文字的 a 标签，并捕获 href（单双引号都要）

示例结果形态（以实际生成为准）：

```regex
<a\s+[^>]*?href\s*=\s*['"]([^'"]+)['"][^>]*>[^<]*(?:下一页|下页)
```

## 10. JSON / 配置埋在 script 里的接口

提示词：

> 从 HTML 的 script 里提取 listApi 后面的接口路径，兼容单双引号

```regex
listApi\s*[:=]\s*['"]([^'"]+)['"]
```

**用工具时的推荐流程**

1. 中文说清楚边界（单双引号、是否懒加载、要不要捕获组）  
2. 贴真实 HTML 片段测匹配数  
3. 用「替换」预览清洗结果  
4. 导出 Python / JS 代码进爬虫
